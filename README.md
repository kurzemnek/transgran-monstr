## Зачем это

Нейросети живут за границей. Телефоны и почты клиентов туда отправлять нельзя — это
трансграничная передача персональных данных, и стоит она от миллиона рублей штрафа.

А отдать выгрузку из CRM нейросети хочется: она за минуту посчитает то, на что
у маркетолога уходит день.

Монстр решает это просто: съедает персональные данные **до того**, как файл попадёт
к модели. Телефон превращается в хеш, имена и свободные тексты исчезают, деньги,
даты, воронки и UTM остаются нетронутыми. Наружу уходят токены, по которым человека
опознать невозможно.

Всё считается на вашем компьютере. Программа никуда ничего не отправляет,
интернет ей не нужен.

## Как пользоваться

1. Выгрузите из CRM что угодно — CSV, Excel, хоть через табуляцию.
2. Перетащите файл на программу. Или сразу несколько — обработает пачкой.
3. Нажмите **СОЖРАТЬ ПЕРСОНАЛЬНЫЕ ДАННЫЕ**.

Рядом ляжет `имя_обезличено.csv`, готовый к отправке в нейросеть.

Перед этим программа показывает разведку — решение по каждой колонке:

```
РАЗВЕДКА
──────────────────────────────────────────────
  [ОСТАВИТЬ]  ID
  [СОЖРАТЬ ]  Название        · похоже на имя человека
  [ХЕШ     ]  Телефон         · станет ключом склейки
  [ХЕШ     ]  E-mail          · станет ключом склейки
  [ОСТАВИТЬ]  Сумма
  [ОСТАВИТЬ]  Воронка
  [ОСТАВИТЬ]  UTM Source
  [СОЖРАТЬ ]  Комментарий     · внутри текста встречаются контакты
──────────────────────────────────────────────
  колонок останется 6 из 8, из них под хешем 2
```

## Что ловит

Решения принимаются по содержимому колонок, а не по названиям: телефон остаётся
телефоном, даже если колонка называется «Контактные данные 2».

| | |
|---|---|
| **Телефоны** | мобильные, городские, 8-800, иностранные с плюсом. Разделителем считает пробел, точку, скобки, дефис, неразрывный дефис и длинное тире из Word |
| **Следы Excel** | апостроф-префикс, хвост `.0`, запись вида `7.9991234567E+10` |
| **Почты** | включая кириллические и спрятанные внутри текста |
| **Имена** | по отчеству, в том числе тюркскому (оглы, кызы), и по инициалам в обе стороны |
| **Документы** | СНИЛС, номера карт с проверкой контрольной суммы |

## Что не трогает

Суммы, даты в любом формате, время, идентификаторы, yclid, UTM, стадии, воронки,
ИНН, штрихкоды EAN-13, IP-адреса, координаты, номера договоров.

Ложная тревога здесь дороже пропуска: от программы, которая врёт, человек просто
отключает проверки. Поэтому «Фамилия Имя» с заглавных ловится только в колонках,
которые сами себя объявили человеческими — «Клиент», «Контакт», «Ответственный».
В обычной колонке этот же рисунок дают «Нижний Новгород» и «Заявка Принята».

## Склейка выживает

Главное, ради чего всё затевалось: одинаковые номера дают одинаковый хеш.
Человек остаётся узнаваемым внутри данных, оставаясь неопознаваемым снаружи.

```
ID    Телефон (хеш)                     Сумма
1001  d68ef6d4647835a9db527ea8b97a2d03  129000     ← +7 999 123-45-67
1002  d68ef6d4647835a9db527ea8b97a2d03   49000     ← 8 (999) 123-45-67
1003  d68ef6d4647835a9db527ea8b97a2d03       0     ← 79991234567
1004  eac05adc9b0730f9644f80313140a125  250000     ← другой человек
```

Три написания одного номера — один человек. Выгрузка за неделю и выгрузка
за полгода стыкуются между собой: ключ создаётся один раз и живёт отдельно
от программы, переживая и переустановку, и переезд на другой компьютер.

На вкладке КЛЮЧ показан его короткий отпечаток — по нему видно, состыкуются ли
две выгрузки, сделанные на разных машинах.

## Проверка перед сохранением

Программа проверяет собственный результат целиком — не выборку, а весь файл.
Если контакт где-то уцелел, файл **не сохраняется вовсе**, а программа называет
колонку и тип находки.

Проверка, которая не умеет уронить сборку, ничего не охраняет.

## Собрать из исходников

Нужен только Python 3.9+. Сторонних библиотек нет вообще.

```bash
python anonymizer.py                      # окно
python anonymizer.py файл.csv --cli       # из консоли, с отчётом по колонкам

pip install pyinstaller
pyinstaller --onefile --windowed --name TRANSGRAN-MONSTR --hidden-import soundtrack anonymizer.py
```

## Что внутри

| файл | что делает |
|---|---|
| `anonymizer.py` | вся программа: распознавание, обработка, проверка, интерфейс |
| `soundtrack.py` | фоновая музыка — синтезируется кодом, не записью |
| `test_challenge.py` | 172 проверки распознавания: половина на то, что обязано ловиться, половина на то, что трогать нельзя |
| `test_anonymizer.py` | склейка между выгрузками, чтение xlsx, поведение проверки |
| `test_security.py` | формулы в выходном файле, раздувание архива, сущности, права на ключ, доверие к источнику обновления |
| `release.py` | манифест обновления для новой версии |

Excel читается своим разбором — `openpyxl` и прочие библиотеки не нужны.
Музыка синтезируется в память и играет оттуда, поэтому после программы
в системе не остаётся ничего, кроме ключа хеширования.

```bash
python test_challenge.py     # ВСЁ СОШЛОСЬ, проверок: 172
python test_anonymizer.py
python test_security.py
```

## Безопасность

Программа читает чужие файлы, пишет файлы, которые потом откроют в Excel,
и умеет обновлять сама себя — поэтому по каждому из этих мест есть проверки
в `test_security.py`, и они гоняются вместе с остальными тестами.

| место | что сделано |
|---|---|
| выходной файл | значения, начинающиеся с `=`, `+`, `@` или таба, обезвреживаются апострофом: CRM — чужой ввод, а Excel выполняет такие ячейки при открытии. Числа при этом не портятся |
| чтение xlsx | книга отклоняется, если распакованный размер превышает лимит или внутри есть объявления сущностей — иначе сто килобайт разворачиваются в шестьдесят мегабайт |
| ключ хеширования | права `600`, папка `700`: по ключу хеши сводятся обратно с телефонами |
| обновление | только `https`, только с закреплённого списка адресов, обязательная сверка контрольной суммы. Манифест без суммы отвергается |
| разбор строк | регулярные выражения проверены на длинных строках: худший случай — 1 мс |

Сторонних зависимостей нет вообще, поэтому чужого кода в программе не исполняется.

## Чего программа не делает

Она **не снимает** с данных статус персональных: пока ключ существует, оператор
остаётся оператором со всеми обязанностями по 152-ФЗ. Она снимает передачу
этих данных за границу — а это ровно та часть, из-за которой нейросети
и оказываются недоступны для работы с клиентской базой.

Свободный текст с персональными данными — комментарии менеджеров, расшифровки
звонков — программа выбрасывает целиком, а не вычищает. Вырезать имена из текста
регулярным выражением нельзя.
